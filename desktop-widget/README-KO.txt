KH Calendar Widget - WebView2 버전

이 버전의 특징
- Microsoft WebView2 기반
- 다른 창 위에 항상 떠 있지 않음
- 둥근 모서리
- GitHub Pages 캘린더와 연결
- 위젯 안 톱니바퀴에서 테마/투명도/글자 크기/블러/위젯 크기 조절
- 오늘 일정/다가오는 일정/미니 달력 표시 여부 설정
- 설정은 이 PC에 자동 저장
- 시계는 1분 단위로 갱신
- 일정은 설정한 주기(기본 10분)마다 갱신
- GIF/지속 애니메이션을 사용하지 않아 CPU/GPU 점유를 줄임
- Windows 로그인 시 자동 실행 가능

설치
1. ZIP을 원하는 폴더에 압축 해제
2. install.cmd 더블클릭
3. 위젯이 실행되면 우측 상단 톱니바퀴로 설정

위젯이 다른 창 뒤에 가면
- 작업표시줄 오른쪽의 ^(숨겨진 아이콘 표시)를 클릭
- KH Calendar Widget 아이콘을 더블클릭

완전 종료
- 트레이 아이콘 우클릭 -> 완전히 종료

제거
- 다운로드해 둔 폴더의 uninstall.cmd 실행

일정 연동
- 일정 데이터: https://rlarudzz.github.io/my-calendar-site/
- 위젯 화면: https://rlarudzz.github.io/my-calendar-site/widget.html
- ChatGPT가 GitHub의 events-data.js를 수정하면 위젯 새로고침 때 반영됩니다.
